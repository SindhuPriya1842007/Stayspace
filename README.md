# StayScape — Complete Frontend

Airbnb-inspired travel platform built with **HTML5 + CSS3 + Vanilla JavaScript**.

## Included
- Public Home, Homes, Experiences, Services, Search Results
- Property / Experience / Service detail pages
- Login and Signup
- Traveller dashboard, profile, wishlist, trips, itinerary, messages, notifications, payments, reviews, settings
- Booking flow: reservation → confirmation
- Host dashboard, listings, create listing, calendar, reservations, earnings, analytics, messages, reviews, profile
- Admin dashboard, users, hosts, properties, experiences, services, bookings, payments, reviews, reports, analytics
- StayScape AI frontend demo
- Responsive CSS
- Mock data and localStorage state

## Run
Open `index.html` with a local static server such as VS Code Live Server.

No backend is required for this frontend demo.
